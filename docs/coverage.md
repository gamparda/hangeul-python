# 지원 현황과 호환성

0.1.0a1의 범위다. 이름 번역의 등록과 실제 동작 검증을 구별한다.

## 구현

- Python 3.13 / 3.14의 모든 기본 예약어와 문맥 키워드 번역.
- 공개 내장 함수·자료형·상수·예외 이름의 번역.
- 조건문, 반복문, 함수, 스코프, 클래스, 생성기, 비동기, 패턴 매칭 등.
- 목록·문자열·사전·집합 등 기본 자료형의 등록된 메서드.
- 속성 읽기·쓰기·증강 대입·삭제, 사용자 한글 멤버 우선.
- 함수별 한글 인자, **확장, 중복 인자 진단.
- 한글 모듈·패키지와 상대 import.
- 동적 코드와 한글 속성 조회.
- 주요 오류의 한글 표시와 원본 위치.
- VS Code 기본 편집 지원.

## 표준 라이브러리

공개 최상위 모듈 이름에는 한글 별칭을 등록했다.
이는 각 모듈의 모든 함수·클래스·속성·인자를 번역했다는 뜻이 아니다.
운영체제 전용 모듈의 실행 가능 여부는 원래 파이썬과 같다.

[3.13 전체 모듈 목록](stdlib-inventory-3.13.json)과
[3.14 전체 모듈 목록](stdlib-inventory-3.14.json)에 모든 최상위 항목을 기록했다.
플랫폼별 구성 차이와 버전 차이를 기록하는 목록이며 하위모듈 전체 목록은 아니다.

- partial_api: 모듈 별칭과 일부 공개 API 번역이 있다.
- module_alias: 모듈 별칭만 있다. API는 영문 이름으로 사용할 수 있다.
- planned: 아직 별칭이 없다.
- internal: 내부 모듈이다. 공개 번역 완료율의 분모에서 제외한다.

수학·경로·JSON·자료 모음·날짜·통계·정규식·비동기·파일 작업 등은 일부 API를 등록했다.
정확한 멤버·인자 이름은 [자동 생성 사전](translation-reference.md)을 따른다.
등록된 이름이 해당 Python 버전·플랫폼에 실제로 있을 때만 사용할 수 있다.

## 외부 패키지

NumPy 배열 생성·일부 집계·모양·자료형,
pandas 자료표 생성·일부 선택·정렬·집계 등을 시험한다.
패키지 전체 번역 완료를 선언하지 않는다. 다른 패키지는 원래 API로 접근 가능하며
JSON 번역 사전을 통해 한글 이름을 추가한다.

## 현재 한계

1. 문맥 키워드 한글 표기의 일반 식별자 사용은 제한한다. 자세한 내용은 명세 3절을 따른다.
2. 출력 값의 True/False/None 표현과 외부 메타데이터 문자열은 원래 파이썬 표현을 유지한다.
3. 오류 분류와 주요 설명을 번역하며 모든 상세 문구의 번역은 아직 완료하지 않았다.
4. 영어 help에 대응하는 도움말 별칭은 제공하지만 함수 문서 본문의 전체 한국어 번역은 남아 있다.
5. 변환된 .py는 hangeul-python 설치가 필요하다. 단일 독립 실행 파일 배포는 지원하지 않는다.
6. 원본 소스 디버깅 위치를 제공하지만 debugpy·분산 실행·multiprocessing의
   모든 시작 방식에 대한 통합 호환성은 검증하지 않았다.
7. 소스는 UTF-8만 지원한다. 원래 입력 데이터를 일괄 번역하지 않는다.
8. 동적 속성·메타클래스·C 확장·커스텀 import hook의 모든 조합에 대한 동등성을 보장하지 않는다.
9. VS Code 자동완성은 사전 기반이며 타입 추론, 전체 언어 서버, 자동 서식은 아직 없다.
10. 실행기는 일반 Python 프로그램과 동일하게 실행된다. 격리 실행 환경은 제공하지 않는다.

## 완료 기준

내장 이름은 빠짐 여부를 자동 검사한다.
표준·외부 API는 공개 API 목록을 분모로 하는 조사와 실제 동작 비교가 추가로 필요하다.
프로젝트의 전체 목표와 후속 작업은 [개발 계획](roadmap.md)에 적는다.

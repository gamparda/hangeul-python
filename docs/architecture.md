# 실행 구조와 설계 결정

## 파이프라인

한글 소스 → 독립 어휘 변환기 → CPython 구문 트리 → 모듈·API 연결 변환 → CPython 실행.

1. lexer.py는 문자열·주석·이름을 구분하고 f/t 문자열의 표현식까지 처리한다.
2. compiler.py는 CPython으로 구문을 해석한다. 변환 전 원본과 위치 대응을 저장한다.
3. 먼저 모듈 별칭을 연결하고 문맥 제약을 검사한다. 함수 밖 return도 이 단계에서 거부한다.
4. API 접근과 한글 키워드 인자를 런타임 호출로 낮춘다.
5. 노드 위치를 한글 원본으로 복원한 뒤 CPython 코드 객체로 컴파일한다.
6. runtime.py가 객체별 사전으로 원래 Python API를 찾는다.

## 독립 어휘 변환기

유효하지 않은 Python 소스를 표준 tokenize에 전달하는 방식에 의존하지 않는다.
이름 토큰의 시작·연속 문자를 구분하며, 이스케이프·중첩 문자열·형식 지정자를 처리한다.
파이썬 전체 표현식의 의미는 별도로 구현하지 않고 CPython 구문 분석기에 위임한다.
참고: [tokenize 입력 제약](https://docs.python.org/3.14/library/tokenize.html).

## 원래 객체 유지

list·dict·NumPy 배열을 다른 자료형으로 감싸지 않는다.
한글 속성 접근에만 해석 함수를 넣는다. 속성 대입에는 일시적인 대입 대상을 사용한다.
자료형 연결은 모듈에 공개된 실제 클래스의 정체성과 MRO로 판단한다.
pathlib처럼 버전마다 구현 클래스의 __module__이 달라져도 공개 Path와 연결된다.
내장 자료형이나 원래 모듈에 한글 속성을 추가하지 않는다.

## 인자와 스코프

한글 인자나 **확장이 있는 호출은 실제 함수의 사전을 조회한다.
사용자 함수 인자는 변환하지 않는다. 원래 함수 표현식과 각 인자는 한 번씩 평가한다.
globals·locals·vars·dir·super·eval·exec처럼 호출 프레임이 의미에 영향을 주는 함수는
호출자 문맥을 따로 처리한다. 한글 상위()를 사용하는 클래스 메서드는 __class__ 셀을 만든다.

## 번역 사전

- data/core.json: 키워드, 내장 이름, 예외, 특수 이름.
- data/api.json: 모듈 별칭, 객체별 멤버, 함수별 키워드 인자.
- Catalog: 중복 키·번역어 충돌·내장 이름 누락·사전 상속 순환 검사.
- 번역 사전은 JSON이며 실행 코드를 포함하지 않는다.
- 외부 패키지를 번역한다는 이유만으로 설치하거나 불러오지 않는다.
- tools/generate_reference.py가 문서와 편집기 자동완성 데이터를 같은 원본에서 생성한다.

## 불러오기

importer.py의 finder는 내장·동결 모듈 처리 뒤에 설치한다.
기존 Python 모듈을 우선하고, .han / .한 파일을 추가로 해석한다.
실행 문맥을 빠져나오면 finder와 추가 경로를 복원한다.
CLI는 실행 중인 소스를 실제 __main__ 모듈로 등록하고 종료 시 이전 상태를 복원한다.

## 위치와 오류

위치는 문자 인덱스와 UTF-8 바이트 열을 구분하여 관리한다.
변환으로 토큰 길이가 달라져도 오류가 원본 한글 소스를 가리키게 한다.
메시지 표시만 번역하며 예외 객체 자체의 의미는 바꾸지 않는다.
한글 진단 템플릿이 없는 상세 문구는 원문을 보존한다.

## 검사

- 의미 비교: 같은 유효 Python 프로그램과 한글판의 결과 비교.
- 회귀: 문자열, f/t 문자열, 원본 위치, 실제 사용자 속성, descriptor, 스코프.
- 통합: 한글 패키지, 파일 입출력, NumPy·pandas, CLI, 생성 Python 파일.
- 배포: wheel과 소스 배포물 생성, 설치한 wheel에서 실행.
- 도구: 정적 검사, 자동 생성 문서 일치, VS Code 확장 문법 검사.

## 남은 설계 과제

전체 공개 API·인자 조사 자동화, 더 넓은 속성 동작의 비교 시험,
완전한 문맥 키워드 처리, 타입에 맞는 자동완성, 표준 디버거와의 깊은 통합,
한글 도움말과 모든 CPython 오류 문구의 관리 체계가 필요하다.

# 한글 파이썬 언어 명세 v0.1

상태: 0.1.0a1에 대응하는 개발 명세. 번역어와 확장 API는 아직 변경될 수 있다.

## 1. 목적과 기준

Python 3.13과 3.14를 기준으로, 한국어 이름으로 파이썬 프로그램을 작성한다.
평가 순서·자료형·예외 계층·스코프·참조·연산은 CPython에 위임한다.
CPython 자체를 수정하지 않는다. 구현된 한글화 계층이 추가하는 동작은 이 명세에 적는다.

영문과 한글 표기를 섞어 쓸 수 있다. 한국어 자연문장의 어순으로 재배열하지 않는다.
예를 들어 `from math import sqrt`는 `에서 수학 불러오기 제곱근`이다.

## 2. 파일과 어휘

- 소스는 UTF-8이며 UTF-8 BOM을 허용한다. 줄바꿈은 LF로 정규화한다.
- 확장자는 .han / .한이다. 패키지 초기화 파일은 __init__.han / __init__.한이다.
- 들여쓰기·기호·숫자·연산자·주석은 기준 파이썬 규칙을 따른다.
- 한글 키워드와 특수 이름은 이름 토큰 단위로 변환한다.
- 주석, 일반 문자열, 원시 문자열의 내용은 번역하지 않는다.
- f/t 문자열은 리터럴을 보존하고 중괄호 안 표현식을 재귀적으로 변환한다.
- f 문자열의 디버그 표기 `f"{참=}"`는 `참=True`를 출력한다.
- 이름 비교 시 Unicode NFKC를 적용한다. 일반 사용자 이름의 최종 정규화는 CPython이 담당한다.
- __han_으로 시작하는 이름은 실행기 전용이다. 소스 코드에서 사용하면 문법 오류다.

문자열에 담긴 코드의 번역은 한글 `평가`·`실행`·`컴파일`에 명시적으로 전달했을 때만 수행한다.
파일 인코딩을 바꾸는 coding 주석은 지원하지 않는다. 입출력 파일의 인코딩은 별도 인자로 지정한다.

## 3. 문법 대응

| Python | 한글 | Python | 한글 |
|---|---|---|---|
| if | 만약 | elif | 아니고만약 |
| else | 아니면 | for | 반복 |
| while | 동안 | in | 안에 |
| def | 함수 | return | 반환 |
| class | 클래스 | lambda | 익명함수 |
| and | 그리고 | or | 또는 |
| not | 아님 | is | 동일 |
| True | 참 | False | 거짓 |
| None | 없음 | pass | 통과 |
| break | 중단 | continue | 계속 |
| import | 불러오기 | from | 에서 |
| as | 별칭 | global | 전역 |
| nonlocal | 비지역 | del | 삭제 |
| try | 시도 | except | 예외 |
| finally | 마지막 | raise | 발생 |
| assert | 단언 | with | 함께 |
| async | 비동기 | await | 대기 |
| yield | 산출 | match | 맞춤 |
| case | 경우 | type | 형별칭 |

`yield from`은 `산출 에서`, `except*`는 `예외*`,
`is not`은 `동일 아님`, `not in`은 `아님 안에`로 쓴다.
컴프리헨션, 데코레이터, 위치 전용·키워드 전용 인자, 타입 매개변수,
패턴 매칭, 생성기, 비동기 문맥 관리자도 같은 구조를 따른다.

0.1에서는 문맥 키워드의 한글 표기도 어휘 단계에서 원문 이름으로 연결한다.
맞춤·경우·형별칭을 일반 변수·속성 이름으로 사용하지 않는 것을 언어 규칙으로 정한다.
현재 구현이 일부 위치에서 이를 허용하더라도 영문 match·case·type과 이름이 합쳐질 수 있다.
문맥을 완전히 구분하는 처리는 향후 호환성 작업이다.

## 4. 내장 이름

내장 함수·자료형·예외 이름은 core.json에 정의한다.
`목록`은 실제 list이고 `값오류`는 실제 ValueError이다.
플랫폼에 없는 내장 이름은 번역 사전에는 있어도 실행 이름공간에는 만들지 않는다.

내장 이름은 예약어가 아니다. 다음처럼 사용자 정의로 덮어쓸 수 있다.

```text
함수 출력(값, 끝):
    반환 값 + 끝
결과 = 출력(1, 끝=2)
```

`출력` 등의 일반 별칭은 원래 파이썬 객체를 참조한다.
속성 조회·동적 실행처럼 한글화를 위해 추가 동작이 필요한 함수는 실행기 구현으로 연결한다.
참과 거짓의 객체는 bool이다. 파이썬 기본 문자열 표현 True/False/None은 바꾸지 않는다.
데이터 문자열, 사전 키, 환경변수 이름, 파일 형식의 필드 이름은 자동 번역하지 않는다.

추가 사전의 identifiers 항목은 원문 식별자와 번역어를 일대일로 연결한다.
등록한 번역어는 문법 분석 전에 복원하므로 선언, 지역 변수, API 속성,
인자 이름을 포함해 소스 전체에서 같은 의미를 갖는다.
원래 Python의 이름공간·콜백 이름·함수 서명은 유지된다.
이 사전의 번역어는 사용자 정의 한글 이름에도 적용되므로 프로젝트에서 예약하여 사용한다.
설정 방법과 충돌 규칙은 [추가 사전](profiles.md)을 따른다.

## 5. 메서드와 속성

`값.추가(3)`은 객체 종류를 확인하여 등록된 원래 API로 연결한다.
사용자 객체를 감싸거나 파이썬 내장 자료형을 수정하지 않는다.
메서드를 변수에 저장했다가 호출할 수도 있다.

1. 실제 한글 속성이 존재하면 그 속성을 사용한다.
2. 동적인 한글 속성 조회가 성공하면 그 값을 사용한다.
3. 그렇지 않으면 객체의 실제 자료형과 MRO에 등록된 번역을 찾는다.
4. 등록이 없으면 일반 파이썬 속성 조회와 같은 오류를 낸다.

실제 한글 property 내부의 AttributeError는 대체 API로 숨기지 않는다.
속성 대입·증강 대입·삭제도 지원하며, 대상 표현식은 한 번 평가한다.
속성 쓰기에서 번역이 없으면 해당 한글 이름을 그대로 쓴다.
특수 메서드의 한글 이름은 소스에서 원래 특수 이름으로 변환한다.
`__초기화__`·`__길이__`·`__반복자__` 등이 이에 해당한다.

## 6. 함수 인자

한글 키워드 인자는 실제 호출 대상에 등록된 사전에 따라 변환한다.

```text
출력("가", "나", 구분="|", 끝="\n")
정렬([1, 3, 2], 역순=참)
```

사용자 함수의 인자명은 그대로 유지한다. `**{"역순": 참}` 같은 확장 인자도
등록된 호출 대상이면 번역한다. 한글·영문 인자가 같은 원문 이름으로 합쳐지면 TypeError다.
원래 API가 위치 전용 인자로 정한 항목은 한글에서도 위치 전용이다.
함수에 없는 인자를 번역 사전이 새로 허용하지 않는다.

## 7. 모듈과 패키지

- `불러오기 수학`은 math를 불러와 수학 이름에 바인딩한다.
- `에서 수학 불러오기 제곱근`은 sqrt를 제곱근 이름에 바인딩한다.
- 등록된 모듈의 별표 불러오기는 원래 공개 이름에 등록된 한글 공개 이름도 추가한다.
- 기존 `.py` 모듈과 패키지의 우선순위를 유지한다.
- 일반 파이썬 모듈이 없으면 .han / .한 파일과 패키지를 찾는다.
- 상대 불러오기는 사용자 패키지 이름을 그대로 보존한다.
- 등록된 표준 모듈 별칭은 절대 불러오기에서 원문 모듈을 가리킨다.
  같은 이름의 지역 모듈을 구분하려면 패키지 안에서 상대 불러오기를 사용한다.
- sys.modules의 키와 모듈 정체성은 원래 파이썬 이름을 유지한다.

모듈 이름의 번역과 그 안의 모든 API 번역은 별도의 지원 항목이다.
원문 영문 멤버는 계속 접근할 수 있다.
플랫폼 전용 모듈은 해당 플랫폼에서만 실행할 수 있다.

## 8. 동적 기능과 반사

`평가`·`실행`은 문자열을 한글 소스로 컴파일한다.
호출한 코드의 전역·지역 이름공간을 기본값으로 사용한다.
명시적인 전역공간·지역공간도 받을 수 있다. 코드 객체도 받을 수 있다.
`컴파일`은 AST 반환 플래그, 최적화, 호출자 future 플래그를 지원한다.
CPython의 비공개 _feature_version 인자는 지원 대상이 아니다.

`속성얻기`·`속성설정`·`속성삭제`·`속성있음`은 문자열로 한글 멤버를 지정할 수 있다.
`속성목록`은 원문 이름과 등록된 한글 이름을 함께 보여준다.
영문 getattr·eval·exec 등은 원래 파이썬 동작을 유지한다.

코드 객체 이름, 스택 프레임 이름공간, 외부 패키지 메타데이터의 모든 문자열을
한국어로 재작성하지 않는다. t 문자열의 표현식 메타데이터에도 변환 후 표기가 나타날 수 있다.

## 9. 오류와 소스 위치

구문 트리의 UTF-8 바이트 위치를 원본 한글 소스 위치로 연결한다.
CLI는 한글 예외 이름·주요 오류 설명·원본 파일과 줄·원래 오류 문구를 표시한다.
원래 예외 타입과 args는 바꾸지 않는다. 사용자 오류 문구도 그대로 둔다.
예외 연결과 예외 묶음의 하위 예외를 표시한다.
등록되지 않은 오류 문구는 원문을 보존한다.

## 10. 파이썬 출력

변환 명령은 API 연결 코드를 포함한 .py 파일을 만든다.
생성된 파일을 실행할 환경에도 hangeul-python 설치가 필요하다.
문서 문자열과 future import 순서를 보존한다. 일반 주석과 원래 서식은 출력에 보존하지 않는다.
생성된 .py 파일의 줄 위치는 생성 파일 기준이다. 원본 디버깅에는 .han 파일을 직접 실행한다.
추가 번역 사전은 생성 코드의 초기화 정보에도 포함된다.

## 11. 버전과 완료 판정

이 명세는 전체 생태계의 완전 호환을 선언하지 않는다.
파이썬 버전별 문법, API 번역, 메시지 번역, 도구 지원을 각각 측정한다.
전체 범위의 완료 기준은 roadmap.md에 정의한다.
